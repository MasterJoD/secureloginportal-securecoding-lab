About the Project

SecurePortal is a practical for the Secure Coding subject. It lets students register, log in, view their profile and manage their details, while administrators can search and manage student records.

The goal is not just a working application but a demonstration of why each protection exists. The README includes a security test plan you can run against this local application.

Tech Stack

  • Frontend: HTML5, CSS3, Bootstrap 5, JavaScript
  • Backend: Python, Flask
  • Database: SQLite
  • Security: Werkzeug hashing, Flask-WTF CSRF
